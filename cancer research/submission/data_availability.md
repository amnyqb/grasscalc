# Data availability statement

No new data were analysed in this study. All values are extracted from the
published sources listed in the reference register. The charting/extraction sheet
(source-level Table S1), the evidence matrix (Table 2), the headline-values
register, the full four-database search strategy, the reference register, and the
smoking-prevalence sensitivity calculation (Table 3, with its reproducible
script) are provided with this submission and will be deposited on the Open
Science Framework (OSF project URL to be inserted on creation).

Saudi Cancer Registry microdata (1994–present), which are the input to the
*proposed* confirmatory analysis (Section 5), were not used here and are not
contained in this package; they are available from the Saudi Ministry of Health
under ethics approval.
